# 太陽系くらべ

水星・金星・地球・火星・木星・土星・天王星・海王星。8つの惑星の太陽からの並び・大きさ・重さ・太陽を1周する時間・岩石/ガス/氷の分け方・環・特徴を当てる1日5問のゲーム。知らなくても遊べます。押すだけ、時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/taiyokei-kurabe/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（まちがえても続く・一発で何問当てられるか）、解いた種類が集まる「惑星帳」があります。
- 問題は「何番目」「岩石・ガス・氷」「特徴」「環」「いちばん大きい」「いちばん近い」「となりの惑星」「1周の時間」「近い順」「大きい順」「いちばん重い」「自転の向き」。正解すると、その惑星の札（何番目・分け方・大きさ・重さ・1周の時間・環）と「なぜ」と出典が出ます。
- 問題は336問（12種類）。チケット・回数制限はありません。
- 文字の大きさは3段から選べます。見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）もあります。
- 機種を変えるときは「引き継ぎ」で、記録をコードと QR にして移せます。

## 中身の出どころ

- [NASA「Planetary Fact Sheet - Ratio to Earth Values」](https://nssdc.gsfc.nasa.gov/planetary/factsheet/planet_table_ratio.html)：太陽からの距離・大きさ（赤道半径）・重さ（質量）・1周の時間・環の有無（地球を1とした比）
- [JAXA 宇宙情報センター](https://spaceinfo.jaxa.jp/ja/)：それぞれの惑星の特徴（金星の温度・火星の赤い色・オリンポス山・大赤斑・土星の密度・天王星の傾き・海王星の発見）
- [日本天文学会「天文学辞典」](https://astro-dic.jp/)：岩石の惑星・ガスの惑星・氷の惑星の分け方
- [国立天文台「冥王星が惑星ではなくなったのはなぜ？」](https://www.nao.ac.jp/faq/a0508.html)：2006年に冥王星が準惑星になったこと

天王星と海王星はガスの惑星に入れる分け方もあります。このゲームは3つに分けます。天王星は横だおしで回っているため、数え方によって自転を逆向きとすることもあるので、自転の問題には出しません。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：画面を開くと文字（Google Fonts）のために Google へつなぐので、文字が端末に保存済みでも Google に IP アドレスが届くことがあります。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（問題と答えは入りません）。
